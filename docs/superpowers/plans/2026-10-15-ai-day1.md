# AI Day-1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the three Day-1 AI-layer artifacts — response envelope, prompt-contract loader with five draft prompts, and the redaction/sample-cap policy — none of which call Bedrock.

**Architecture:** `ToolResult[T]` wraps every (future) tool call, separating the untrusted model `payload` from Python-computed `AuditMeta`. Prompts live as versioned `.md` files loaded by a tiny cached loader. Cap numbers live in `settings.py` beside the existing §15 demo guardrails; `ai/policy.py` owns redaction + log-allowlist *logic* and reads caps from settings (DRY — no duplicate numbers).

**Tech Stack:** Python 3.12, Pydantic v2, pydantic-settings, pytest. All commands run from `backend/`.

**Spec:** `docs/superpowers/specs/2026-10-15-ai-day1-design.md`. Master plan: `docs/design.md` (§10 tools, §14.3 minimization, §15 budget).

**Refinement from spec:** The spec showed caps as constants inside `policy.py`. During file mapping we found `settings.py` already defines `max_data_rows=50_000`, `max_workbook_mb=25`, `bedrock_max_tokens=2048` under a "Demo guardrails (§15)" block. To stay DRY, the two genuinely-new caps go into `settings.py` with the others, and `policy.py` re-exports all four from settings. `redact_sample` drops the unused `col_semantic` param from the spec sketch (YAGNI) — it is a shape-preserving mask for log/display safety.

```python
"""AI-safety policy (§14.3, §15): prompt/sample caps, sample redaction, log allowlist.

Caps are re-exported from settings so there is one source of truth; the demo
guardrails already define rows/tokens. Redaction and the log allowlist keep raw
sensitive cell values out of prompts' logs and any logged payload.
"""
from app.settings import settings

MAX_ROWS = settings.max_data_rows
MAX_OUTPUT_TOKENS = settings.bedrock_max_tokens
MAX_SAMPLES_PER_COLUMN = settings.max_samples_per_column
MAX_CANDIDATE_MATCHES = settings.max_candidate_matches

# Only these keys may ever be logged (§14 / §16): hashes, IDs, counts — never cell values.
SAFE_LOG_FIELDS = {
    "tool", "model_id", "prompt_version", "input_hash", "output_hash",
    "latency_ms", "input_tokens", "output_tokens", "row_count",
}


def safe_log(d: dict) -> dict:
    """Drop every field not on the allowlist, so raw values can't leak into logs."""
    return {k: v for k, v in d.items() if k in SAFE_LOG_FIELDS}


def redact_sample(value: str) -> str:
    """Shape-preserving mask for logs/display: digits->#, letters->x, punctuation kept."""
    return "".join("#" if c.isdigit() else "x" if c.isalpha() else c for c in value)
```

```python
"""Versioned prompt loader (§10.1, §14.3). Prompts live as prompts/<tool>.<version>.md.

Day 1: drafts only — these are reviewed as prose and pinned by version; they are
not wired to Bedrock until Day 2.
"""
from functools import lru_cache
from pathlib import Path

PROMPTS_DIR = Path(__file__).resolve().parent.parent / "prompts"

TOOLS = (
    "tool1_semantics",
    "tool2_types",
    "tool3_formulas",
    "tool4_standardize",
    "tool5_update",
)


@lru_cache
def get_prompt(tool: str, version: str = "v1") -> str:
    return (PROMPTS_DIR / f"{tool}.{version}.md").read_text(encoding="utf-8")
```

````markdown
# Tool #1 — Semantic verification (v1)

You verify what a requested new column means and identify which EXISTING columns
could be its source. You do NOT create any values.

## Inputs
- comment_name: {comment_name}
- requested output header: {output_header}
- current headers: {current_headers}
- normalized headers: {normalized_headers}
- main-file headers (if any): {main_headers}
- per-column type summaries: {type_summaries}
- bounded sample values with evidence cell IDs: {samples}

## Rules
- Identify candidate source columns ONLY from the headers listed above. Do not invent headers or column IDs.
- You may not produce any new cell values — only verify meaning and point to evidence.
- confidence is 0..1. Use status "ambiguous" whenever a human must choose; "not_found" when no column fits.

## Output — JSON only, matching this shape
```json
{
  "meaning": "string",
  "existing_column_matches": [{"column_id": "string", "confidence": 0.0, "reason": "string"}],
  "recommended_output_header": "string",
  "interpretation": "string",
  "confidence": 0.0,
  "status": "confirmed | ambiguous | not_found",
  "questions_for_human": ["string"]
}
```
````

````markdown
You propose normalized values for one column flagged as having mixed types. The

## Inputs

  "target_type": "string",
````

````markdown
You match unresolved current rows to candidate main rows. You receive ONLY the
unresolved candidates, never the whole workbook.
````
