## Task 1: Pin-guard test over all five tools

Locks the prompt↔version↔field linkage. `render_prompt` fills placeholders by `str.replace("{field}", ...)`, so a field in `_FIELDS` with no matching `{placeholder}` in the prompt silently sends an unfilled prompt — this test catches that, plus a renamed/deleted prompt file or a non-`v1` version.

**Files:**
- Create: `backend/app/tests/test_ai_day7.py`

- [ ] **Step 1: Write the guard test**

```python
"""Day-7 AI wrap-up: guard tests that lock the prompt/version pinning and the two
adversarial gaps not already covered by Days 3-5. All offline (crafted fake responses)."""
import importlib

import pytest
from pydantic import ValidationError

from app.ai.bedrock_client import BedrockClient, _extract_json
from app.ai.prompts import get_prompt

# (module path, run fn name, TOOL const, PROMPT_VERSION, _FIELDS) — resolved via import below.
TOOL_MODULES = [
    "app.ai.tool1_semantics",
    "app.ai.tool2_types",
    "app.ai.tool3_formulas",
    "app.ai.tool4_standardize",
    "app.ai.tool5_update",
]


@pytest.mark.parametrize("modpath", TOOL_MODULES)
def test_prompt_version_and_fields_are_pinned(modpath):
    mod = importlib.import_module(modpath)
    # version pinned to v1
    assert mod.PROMPT_VERSION == "v1", f"{modpath} drifted off v1"
    # prompt file exists for (TOOL, v1)
    text = get_prompt(mod.TOOL, "v1")  # raises FileNotFoundError if renamed/deleted
    # every declared field has a matching placeholder in the prompt
    missing = [f for f in mod._FIELDS if "{" + f + "}" not in text]
    assert not missing, f"{modpath} fields without a placeholder in prompt: {missing}"
```

Run: `cd backend && python -m pytest app/tests/test_ai_day7.py::test_prompt_version_and_fields_are_pinned -v`
Expected: 5 PASS (one per tool). A FAIL means a prompt/field/version actually drifted — fix the mismatch, don't edit the test.

class _FakeBedrock:
    """Returns a fixed text body from converse(), like the Day 3-5 fakes."""

    def __init__(self, text: str):
        self._text = text

    def converse(self, **kwargs):
        return {
            "output": {"message": {"content": [{"text": self._text}]}},
            "usage": {"inputTokens": 1, "outputTokens": 1},
        }


def _client(text: str) -> BedrockClient:
    return BedrockClient(client=_FakeBedrock(text))


def test_extract_json_rejects_response_with_no_object():
    with pytest.raises(ValueError, match="no JSON object"):
        _extract_json("sorry, I can't help with that")
```

def write_report(rows, failures, docs_dir: Path) -> tuple[Path, Path]:
    """Persist the run as markdown + json. Returns (md_path, json_path)."""
    docs_dir.mkdir(parents=True, exist_ok=True)
    md_path = docs_dir / "ai-eval-day7.md"
    json_path = docs_dir / "ai-eval-day7.json"
    md_path.write_text(format_report(rows, failures), encoding="utf-8")
    json_path.write_text(
        json.dumps({"rows": rows, "failures": failures or []}, indent=2),
        encoding="utf-8",
    )
    return md_path, json_path
```

## Confidence-band behavior

- Every tool's output is an untrusted proposal; nothing auto-applies.
- `ambiguous` proposals and `safe` proposals below the confidence floor are demoted to human review (Tools #2/#4/#5). A human selects at both review gates.
- Models may only *select* from candidate IDs/values supplied in the prompt; invented IDs/headers/canonicals are rejected whole.

## Known limitations

- **Summary-row / column totals are deferred** — the demo supports row-wise formulas only.
- **Update mode skips unmatched rows** — inserting unmatched rows is deferred.
- **Formulas are syntax-verified, not calculated** — OpenPyXL does not evaluate; output is labeled accordingly.
- **Region-locked model access** — cross-region inference profiles (`us.*`, `apac.*`) hit an org SCP deny; only bare us-east-1 Nova ids work in this account.
