# Application redesign

Mode: Operate. Scope: all frontend routes and workflow states.

## Direction contract

THESIS: A guided workbook workspace. One visible task and next action replaces stacked status cards and disconnected controls.

OWN-WORLD: Swiss composition, white and neutral #F7F7F8, Helvetica Neue, #002FA7 selection and actions, fine rules, restrained semantic colors. Familiar web controls and readable data take priority.

STORY: Upload and describe a change, confirm worksheets, review evidence, decide, and download a separate output. Technical diagnostics remain available on demand.

FIRST VIEWPORT: A compact top navigation preserves usable width. Page title and task description lead into a work area. Reviews show decision progress above a list and evidence pane, with an anchored submission bar. Creation starts with the real file input; progress leads with the current task; results lead with the output file.

FORM: Candidate 6, Swiss information design as used in financial reporting; seed:2ee90034d968cbe9. Signature: decision progress paired with a direct route to the next undecided item, including items hidden by filters. Code-led implementation, as authorized by the full redesign brief.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Grounded alternatives considered

1. Annual-report typographic hierarchy. 2. Institutional identity manuals. 3. Financial publication information density. 4. Filing and document indexing. 5. Proofreading and editorial annotations. 6. Swiss information design. 7. Banking stationery restraint.

The split-flap challenger loses clarity through fixed-cell typography; retain its stable alignment discipline. Botanical sequencing loses audience identification; retain a consistent scale across workflow stages. The brief's explicit minimalism, English language, and complete implementation authorization govern the final system.
