# Generated backend API types

`backend.ts` is generated by `openapi-typescript` from the actual FastAPI
`/openapi.json`. The downloaded contract is pinned at `frontend/openapi/backend.json`.
Do not edit generated types by hand.

From `frontend/`, with the backend running on port 8000:

```powershell
npm.cmd run api:generate
```

Set `OPENAPI_URL` to an approved alternative schema URL when needed. To regenerate
deterministically from the pinned snapshot without a running server:

```powershell
npm.cmd run api:generate:offline
```

See [the generator documentation](https://openapi-ts.dev/node) and
[current integration status](../../../INTEGRATION.md). The contract contains no
pre-start metadata or confirmed-header persistence operation. Generated types do
not establish deployed authentication or replace runtime response validation.
